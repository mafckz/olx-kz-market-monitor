# Мониторинг объявлений OLX.kz

Этот контекст описывает поисковые критерии, объявления OLX, сведения о продавцах и историю изменений предложений.

## Поиск и цены

**Профиль поиска**:
Набор критериев одного независимого поиска: категория, цель/модель, включающие и исключающие признаки, ценовой диапазон, география и режим анализа. Один профиль можно приостанавливать, возобновлять и настраивать отдельно.
_Avoid_: Жёстко заданный поисковый запрос

**Одноразовый поиск по Казахстану**:
Ручной поиск по всей стране, который создаётся как временный запуск из Telegram и не меняет сохранённые профили.
_Avoid_: Изменение географии активного профиля

**NVIDIA GeForce RTX 3080**:
Точная модель видеокарты для стартового профиля поиска; RTX 3080 Ti считается отдельной моделью.
_Avoid_: RTX 3080 Ti

**Ценовой сегмент**:
Один из трёх постоянных интервалов — нижнего, среднего или верхнего — между минимальной и максимальной ценой профиля, разделённых на равные части. Для стартового диапазона 200 000–500 000 ₸ границы проходят на 300 000 и 400 000 ₸.
_Avoid_: Динамическая треть выдачи

**Классификатор**:
Локальные правила, которые разбирают запрос и отбирают совпадения без обращения к AI API; исходный режим профиля.
_Avoid_: AI-режим

**AI-режим**:
Необязательный анализатор на OpenAI API, получающий только пользовательский запрос или уже собранные разрешённым адаптером данные объявления. Его использование ограничено локальным месячным бюджетом и не позволяет модели самой обходить OLX.
_Avoid_: Автономный веб-агент

## Объявления и продавцы

**Объявление OLX**:
Предложение на OLX.kz, идентифицируемое ID объявления и ссылкой на его страницу; сохранённые данные включают обнаруженное состояние и историю существенных изменений.
_Avoid_: Результат поиска

**Подробная проверка**:
Ежедневная повторная проверка активных страниц объявлений на изменения, которые не видны в карточках выдачи; ссылка на профиль продавца доступна для ручной проверки.
_Avoid_: Полный скан

**Оценка продавца**:
Предварительный вывод о вероятной частной продаже или перепродаже, обоснованный наблюдаемыми признаками на разрешённой странице объявления; профиль продавца можно открыть по ссылке вручную. Это не установленный статус продавца.
_Avoid_: Подтверждённый статус продавца

**Глубокая проверка**:
Ежедневное повторное чтение активных карточек объявлений для поиска изменений описания, характеристик и доступности, которые не видны в выдаче.
_Avoid_: Обход профиля продавца
