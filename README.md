# OLX Market Monitor

Локальный монитор объявлений OLX.kz. Владелец управляет поисковыми профилями и получает уведомления через личного Telegram-бота. Стартовая цель: подержанные настольные компьютеры в Алматы с NVIDIA GeForce RTX 3080 за 200 000–500 000 ₸. Данные остаются локально; архитектура поддерживает несколько профилей и новые категории товаров.

## Статус

Основная кодовая база реализована, но живой поиск OLX в текущей среде заблокирован HTTP 403 на проверке `robots.txt`; полная выдача и автоматизация не подтверждены. Локальная настройка с Telegram token, запуск Windows-задачи и повторяющийся сбор ещё не проверены. Архитектура разделяет локальное ядро, OLX-адаптер, Telegram-управление и расписание. Для каждого OLX-запроса проверяется актуальный `robots.txt`; запрещённые пути не обходятся. Автоматический сбор профилей продавцов исключён.

## Быстрый старт разработки

Требуется Python 3.12+ и Windows Credential Manager:

```powershell
.\scripts\setup.ps1 -Configure -InstallTask
```

Скрипт создаст виртуальное окружение, установит приложение, проверит Telegram token, сохранит секреты в Windows Credential Manager, покажет одноразовый код привязки и установит задачу автозапуска.

Для ручной установки шагами:

```powershell
.\scripts\setup.ps1
.\.venv\Scripts\python.exe -m olx_monitor configure
.\scripts\setup.ps1 -InstallTask
```

Задача стартует после входа владельца в Windows. Она запускает бота сразу, поэтому покрывает пропущенные циклы, пока компьютер был выключен.

Секреты не хранить в файлах репозитория. SQLite, локальная конфигурация, отчёты и журналы хранятся в `%LOCALAPPDATA%\OLXMarketMonitor` и исключены из Git.
