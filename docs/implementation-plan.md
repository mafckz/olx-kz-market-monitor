# План разработки OLX Market Monitor

**Статус:** разработка начата 22 октября 2026 г.

## Цель и первая поставка

Локальный помощник, которым владелец управляет с телефона через личного Telegram-бота. Он сохраняет несколько поисковых профилей, регулярно собирает подходящие объявления OLX.kz, сообщает о новых предложениях и изменениях, ведёт историю и готовит локальную сводку. Первым проверяемым профилем служат подержанные настольные компьютеры в Алматы с точной NVIDIA GeForce RTX 3080 по цене 200 000–500 000 ₸.

Приложение работает на Windows под учётной записью владельца. SQLite, отчёты и секреты остаются локальными и не попадают в Git.

## Принятые требования

- Несколько одновременно включённых профилей; каждый хранит собственную категорию, запрос/модель, исключения, цену, географию и режим анализа.
- Стартовый профиль: настольные компьютеры, б/у, RTX 3080; исключить Ti, ноутбуки и отдельные видеокарты; Алматы; 200 000–500 000 ₸ включительно.
- Фиксированные ценовые интервалы для стартового профиля: 200 000–<300 000, 300 000–<400 000 и 400 000–500 000 ₸.
- Поиск по Казахстану — отдельная одноразовая команда; профиль постоянного поиска при этом не меняется.
- Telegram — единственный канал первой версии. Бот принимает команды только от Telegram-аккаунта, привязанного одноразовым кодом локальной установки.
- Запуск при входе в Windows; обычный цикл — каждые два часа. Суточная глубокая проверка повторно открывает активные карточки, чтобы находить изменения описания.
- Без изменений — без повторного открытия карточки и без уведомления. Один сводный Telegram-отчёт по новым и изменённым карточкам; при отсутствии изменений бот молчит.
- Данные страницы продавца не обходить. Сохранять только сведения, показанные в разрешённой карточке объявления, и ссылку на профиль для ручной проверки. Оценка продавца всегда предварительная и сопровождается наблюдаемыми признаками.
- Два режима профиля: классификатор без API по умолчанию и необязательный AI-анализ OpenAI для разбора запросов и новых/существенно изменённых карточек. AI работает только с собранными данными, без своего браузинга, просмотра профилей, контакта или торга с продавцом.
- Для AI нужен отдельный OpenAI API key и настраиваемый месячный лимит расходов. При исчерпании лимита профиль продолжает работать классификатором.
- Установка — одноразовая локальная настройка: Telegram Bot Token, опциональный OpenAI API key, лимит AI-расходов и код привязки вводятся на Windows; секреты хранятся через системное хранилище учётных данных.
- Локальная база — SQLite, отчёт — Markdown. База, отчёты, логи с пользовательскими данными и секреты исключены из Git.

## Архитектура

```text
Telegram (личный чат)
       │ команды, черновики поиска, сводки
       ▼
Bot / application service ─────── optional OpenAI Responses API
       │                               (лимитированный расход)
       ├── profile parser + confirmation
       ├── scheduler (2 ч + daily deep)
       ▼
OLX collector ── robots.txt gate ── public category and ad pages
       │
       ▼
SQLite ── listing history / profile links / run log / AI budget
       └── Markdown report
```

Слой источника отделён от профилей и Telegram. Начальная реализация OLX использует публичную категорию, её поисковые URL и карточки объявлений. Перед каждым запросом проверяется актуальный `robots.txt`; запрещённый путь отклоняется без попытки обхода. Селекторы HTML считаются внешней изменяемой зависимостью, поэтому ошибка разбора должна быть видна владельцу, а не выглядеть как пустая выдача.

Запись объявления глобально уникальна по ID OLX. Связь с профилями хранится отдельно. Изменение карточки сравнивается по существенным полям: заголовок, цена, город, состояние и описание/характеристики при глубокой проверке. Повторное совпадение в нескольких профилях не создаёт дубликат объявления или уведомления.

## Этапы

### Этап 1 — локальное ядро и Telegram MVP

- Структура Python-пакета, конфигурация и CLI установки/запуска.
- SQLite-схема, миграция/инициализация стартового профиля, история объявлений и запусков.
- Безопасное хранение Telegram/OpenAI ключей в Windows Credential Manager через системный keyring.
- Личный Telegram-бот, одноразовая привязка владельца, справка, статус, список профилей, создание профиля через текстовый запрос и подтверждение, ручной запуск, одноразовый поиск по Казахстану, просмотр сводки.
- Регулярный двухчасовой цикл и суточный глубокий цикл в одном процессе.
- Windows Task Scheduler: запуск при входе владельца, автоперезапуск процесса при ошибке.

**Сделано в первой кодовой итерации:** Python-пакет и CLI, локальная схема SQLite и стартовый профиль, текстовый разбор/подтверждение новых профилей, личный Telegram-бот с pair-code и командами управления, циклическое расписание, Markdown-отчёт, правила продавца/торга и учёт резерва OpenAI расходов. Реальная работа Telegram начинается после локального ввода токена и привязки; эти секреты не доступны в репозитории.

### Этап 2 — сбор и нормализация OLX

- Адаптер категории настольных компьютеров с пагинацией, фильтром цены, города и состояния.
- robots.txt gate, ограничение частоты запросов, короткие таймауты и повторные попытки только для временных ошибок.
- Разбор карточек выдачи и карточек объявлений; нормализация цены, локации, характеристик, даты и публичных сведений продавца.
- Точный классификатор RTX 3080; отдельная очередь сомнительных совпадений; исключения для Ti, ноутбуков и отдельных GPU.
- Ошибки загрузки и изменения HTML отражаются как ошибки запуска и отправляются владельцу.

### Этап 3 — уведомления и оценка предложения

- Дедупликация по ID между профилями; события новых объявлений и существенных изменений.
- Telegram-сводка, Markdown-файл, распределение по фиксированным ценовым сегментам.
- Относительная цена считается только при наличии минимум пяти активных похожих объявлений.
- Фактические основания для торга: указанная договорная цена, видимые недостатки, комплектность, цена относительно сопоставимых объявлений.
- Предварительная оценка частник/перепродавец сопровождается признаками и уровнем неопределённости; профиль продавца автоматически не читается.

### Этап 4 — опциональный AI-режим

- AI-парсер естественно-языкового запроса и структурированный preview перед сохранением профиля.
- AI-анализ новых и существенных изменений с отделением фактов страницы от вывода модели.
- Предварительный резерв расходов, месячный локальный лимит, учёт фактического использования API; на лимите — тихий fallback на классификатор с заметкой в сводке.
- Проверка на размеченной вручную выборке до включения AI по умолчанию; профили по умолчанию остаются в режиме классификатора.

### Этап 5 — удобство управления и расширение каталога

- Пауза/возобновление/редактирование/удаление профилей, уточнения и просмотр очереди сомнительных совпадений.
- Шаблоны профилей для новых категорий и товаров; каталог категорий/правил разбора отделён от общей логики мониторинга.
- Версионирование схемы и экспорт/резервная копия локальной базы.

## Готовность первой версии

Первая версия считается готовой к использованию, когда владелец на чистой Windows-машине может выполнить настройку, привязать Telegram, подтвердить стартовый профиль, получить реальные результаты категории OLX, увидеть сохранение/дедупликацию/изменение в SQLite и Markdown, запустить расписание и получить сводку. AI остаётся выключенным до отдельной настройки и проверки лимита расходов.

## Текущая последовательность работ

1. Зафиксировать согласованные требования и архитектуру в документах.
2. Реализовать ядро SQLite, профили и модель событий.
3. Реализовать разрешённый robots.txt-совместимый OLX-адаптер.
4. Подключить Telegram и локальную настройку секретов.
5. Добавить расписание Windows и сводки.
6. Включить optional AI после проверки бюджета и API-конфигурации.
