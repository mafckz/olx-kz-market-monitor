# Требования к OLX Market Monitor

**Статус:** согласовано; первая поставка в разработке.
**Последняя проверка `robots.txt`:** 22 октября 2026 г.

## Цель

Находить и сравнивать объявления на OLX.kz, начиная с подержанных настольных компьютеров с точной NVIDIA GeForce RTX 3080. Владелец управляет поисками со смартфона через Telegram. Факты со страницы сохраняются отдельно от предварительных выводов о совпадении, продавце и выгодности предложения.

## Начальный профиль

- Категория: «Компьютеры и комплектующие → Настольные компьютеры».
- Состояние: б/у.
- Точная модель: NVIDIA GeForce RTX 3080; исключить RTX 3080 Ti, ноутбуки и отдельные видеокарты.
- Цена: от 200 000 до 500 000 ₸ включительно.
- География: Алматы.
- Фиксированные сегменты: нижний — 200 000 ≤ цена < 300 000 ₸; средний — 300 000 ≤ цена < 400 000 ₸; верхний — 400 000 ≤ цена ≤ 500 000 ₸.

Профиль хранит категорию, товар/модель, включающие и исключающие признаки, цену, географию и режим классификации. Архитектура допускает несколько активных профилей и будущие категории, не вшивая RTX 3080 в общую логику.

## Управление и команды

- Личный Telegram-бот; при установке владелец вводит токен от `@BotFather` локально и привязывает личный Telegram-чат одноразовым кодом, показанным на Windows-компьютере.
- Команды и запросы принимает только привязанный владелец. Другим пользователям бот не раскрывает состояние, профили и объявления.
- Запрос на новый поиск разбирается в черновик. Бот показывает категорию, цель, цену, город и исключения и сохраняет профиль только после явного подтверждения.
- Поддержать просмотр/паузу/возобновление профилей, ручной запуск, сводку и одноразовый поиск по всему Казахстану. Последний не меняет постоянный профиль.
- По умолчанию разбор ведёт локальный классификатор. AI — отдельный режим профиля, включаемый владельцем.

## Сбор объявлений

- Регулярный запуск раз в два часа; при входе владельца в Windows выполнить пропущенный запуск.
- Обходить все доступные страницы выдачи в пределах настройки источника, фильтруя цену, географию и состояние. Ограничение максимальной страницы и факт неполной выдачи отражать в запуске.
- Новое объявление или изменение видимых существенных полей инициирует загрузку карточки. Неизменённое объявление не открывать снова, кроме суточной глубокой проверки.
- Раз в сутки проверять активные карточки объявлений на изменение описания, характеристик и статуса.
- Существенные поля: цена, заголовок, описание, город, состояние, основные характеристики и доступность объявления. Технические изменения страницы/счётчиков сами по себе не рассылаются.
- Дедупликация глобальна по ID объявления OLX; одно предложение в нескольких профилях связывается со всеми совпавшими профилями.
- Совпадения с недостаточной уверенностью помещать в отдельную очередь ручной проверки.

## Данные и анализ

Сохранять ID, ссылку, цену, заголовок, описание, дату публикации (если доступна), дату первого обнаружения, последней проверки, город, состояние, признаки комплектации/недостатков, распознанные характеристики, публичные сведения о продавце из карточки, ссылку на профиль и историю существенных изменений.

Для оценки соответствия профилю и перспективности использовать объяснимые признаки и исходный текст. Сравнение цены с медианой показывать только при наличии не менее пяти похожих активных объявлений. Основания для торга формулировать как наблюдаемые факты: договорная цена, явно указанные недостатки/неполная комплектация и сравнение с сопоставимыми объявлениями.

Предварительная оценка «похоже на частника / сборщика / перепродавца» должна перечислять основания и уровень неопределённости. Частное лицо или магазин нельзя выдавать за установленный факт.

## Профили продавцов и ограничения OLX

Владелец ранее согласовал сохранять только то, что доступно на разрешённой странице объявления, и ссылку на профиль для ручной проверки. Список активных объявлений и историю профиля автоматически не собирать.

Перед каждым автоматическим HTTP-запросом источник сверяет целевой URL с актуальным `https://www.olx.kz/robots.txt`. Запрещённые пути, включая `/search/` и `/list/user/` в проверенной редакции файла от 22.10.2026, должны отклоняться без обхода запрета. Разрешённые URL категорий вида `/.../q-.../`, карточки объявлений и страница robots запрашиваются с низкой частотой. При изменении правил адаптер останавливает запрос и сообщает владельцу.

Селекторы OLX не являются стабильным API. Ошибку разбора нельзя трактовать как пустой результат: запуск должен завершиться диагностикой, сохранить ошибку и сообщить владельцу. При блокировке/капче/ограничении доступа автоматические попытки должны останавливаться и требовать ручного решения, а не обходить защиту.

## Режим AI

- Один профиль использует либо правила/классификатор, либо AI-агента; по умолчанию выбран классификатор.
- Агент используется для разбора пользовательского запроса и объяснения новых/существенно изменённых карточек, но получает только текст пользователя и данные, уже собранные разрешённым OLX-адаптером.
- Агент не обходит OLX самостоятельно, не открывает профиль продавца и не контактирует с ним.
- AI-режим требует отдельного OpenAI API key, введённого локально, и месячного расходного лимита в USD. До каждого вызова резервируется консервативная оценка стоимости; при достижении лимита API не вызывается, профиль продолжает работу классификатором. Локальный учёт показывает оценку расходов и не заменяет лимит аккаунта OpenAI. Модель и цены токенов настраиваются в установщике; начальные значения относятся к gpt-6-luna и проверены по [официальной странице модели OpenAI](https://developers.openai.com/api/docs/models/gpt-6-luna) 22 октября 2026 г.
- Ключ хранится в Windows Credential Manager; в базе и Git ключа нет. ChatGPT и OpenAI API имеют отдельные условия и биллинг.

## Хранение и отчёт

- SQLite: локальная база объявлений, профилей, событий, запусков и локального AI-учёта.
- Markdown: актуальная сводка по профилям, сегментам цены, новым объявлениям и изменениям.
- Telegram: один компактный отчёт на запуск, если есть новые/изменённые/ошибочные данные; без шума при полном отсутствии изменений. Длительные ошибки сообщаются после исчерпания повторных попыток.
- База, отчёты, секреты, журналы с локальными данными и временные файлы не коммитятся в Git.

## Платформа и установка

- Python на Windows; бот выполняется в фоне под учётной записью владельца.
- Однократная пошаговая локальная настройка сохраняет токены в Windows Credential Manager, создаёт SQLite/стартовый профиль и показывает код Telegram-привязки.
- Windows Task Scheduler запускает бота при входе пользователя; приложение выполняет двухчасовое и суточное расписание самостоятельно.

## Нерешённые детали реализации

Эти детали проверяются в коде/на локальном запуске и не меняют согласованные продуктовые требования:

1. Поддерживаемый диапазон Python и версии HTML-селекторов OLX.
2. Максимальное число страниц одного прохода и способ явно показать достижение лимита OLX.
3. Границы ценовых сегментов для профилей с иным диапазоном: равные трети от границ каждого профиля.
4. Точные признаки состояния/доступности и восстановление после временной ошибки сети.
5. Модель, цены токенов и максимальный размер AI-запроса; конфигурация должна хранить дату сверки цен OpenAI.
